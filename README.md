# ReelCut

Macの画面収録を、外国CM風のオープニング付きデモ動画に仕上げる、ブラウザだけで動く動画エディタ。
無音・BGMなし。X / LinkedIn にそのまま投稿できる **mp4（H.264）** で書き出し。

## できること
- **オープニング**：「you」「can」「now」が1文字ずつ → 画像モンタージュ（最初ゆっくり→加速。足りない分はズーム・回転・反転・フィルタで水増し）→ 一呼吸 → 用途テキストをフレーズごとに → 全文ドーン → **文字に向かってパンチズーム → 突き抜けた先に本編**（白フラッシュ付き、長さ調整可）
- **本編**：画面収録（.mov / .mp4）を複数追加・結合（順番入替可）。再生バーは1本につながって見える
  - クリック：その時点へ
  - **ダブルクリックしてそのままドラッグ**：範囲選択（ドラッグ中はその時点の映像を表示）→ 離すと「字幕 / 倍速 / カット」
  - 字幕：単語ごとに色が移っていくカラオケ式（日本語も単語分割）
  - 倍速：1.5 / 2 / 3 / 4 / 8 / 16 倍
  - カット：その範囲を飛ばす
- **エンディング**：タイピング風にアプリ名（＋サブテキスト）
- **カット演出**：カット箇所は、ウィップ（高速スライド＋モーションブラー＋フラッシュ）／パンチズーム／グリッチ／なし（シームレス）から選択。既定をクリップタブで決め、カットごとに個別指定もできる
- **モンタージュの加速度**：切り替わりが速くなっていくカーブの強さを調整（1＝一定、大きいほど最後に一気に加速）
- **動画の型**：新規タブを開くと、OP/EDが自動再生される選択画面で型を選べる（後から変更可）
  - **Classic**：「you / can / now」→ モンタージュ → 用途ドーン → パンチズーム → 本編。ED はタイピング。既定は黒背景・白文字。サムネは黒＋斜線
  - **Typewriter**：文章をタイプ → じわっと流れる → 一瞬で退場 → 次の文章…→ 加速モンタージュ → 最後の1枚で止めて本編。ED は PR文をタイプ → 退場 → アプリ名をタイプ。既定は白背景・黒文字。サムネは白＋リング
  - 背景色・文字色・フォント（サンセリフ／明朝／等幅）はどの型でも変更可（「既定に戻す」あり）
- **先頭タイトルカード**：一番最初の数フレームだけアプリ名を表示（SNSのサムネイルがこれになる）。Classic は黒＋斜線、Typewriter は白＋リング
- **🧩 埋め込み**：本編の好きな位置に挿入できる
  - **スライド**：文字（改行・太字・下線・部分的なサイズ変更。ドラッグで選んだ部分だけに適用）＋スライドごとの背景色・文字色（既定は動画の型の色）。文字の出方は型に合わせる。複数枚つなげられ、各スライドに動画も載せられる（「✂ 再生バーで編集」で、下の再生バーがその動画になり、字幕 / 倍速 / カットがいつも通りできる）。文字だけ・動画だけ・両方、どれも可
  - **動画モンタージュ**：複数の動画を追加 → 順番・使う範囲を指定 → 最初ゆっくり→加速で切り替え。未指定なら追加順・先頭から
  - **配置**：「📍 位置を決める」→ 再生バーをクリック →「✓ 決定」。紫のマーカーが付き、クリックで編集。本編はその分後ろにずれる
- **複数プロジェクト**：ヘッダー下のタブで「＋ 新規」→ まっさらから別の動画を並行編集。タブ切替は即座、ダブルクリックで名前変更
- **プレビュー**：オープニング〜本編〜エンディングを通しで再生
- **書き出し**：1920×1080 / 1280×720 / 1080×1080 / 1080×1920、30fps、mp4。Chrome推奨（他ブラウザは webm フォールバック）
- 動画・画像はブラウザ内（IndexedDB）に保存。リロードしても消えない

## 使い方
1. Chrome で `index.html` を開く
2. 「📹 クリップ」で画面収録を追加（複数可、ドラッグ＆ドロップ可）
3. 「🎞 オープニング」で単語・用途テキスト・画像（アップロード or Cmd+V で貼り付け）を設定
4. 再生バーで範囲を選んで字幕 / 倍速 / カット
5. 「🔚 エンディング」でアプリ名
6. 「⬇ 書き出し」→ mp4 を保存 → X / LinkedIn に投稿

## 注意
- Macの画面収録は標準で **無音**（マイクを選ばない限り）。このアプリも無音で書き出します
- 書き出しは「動画の長さ × 0.5〜1.5倍」程度の時間がかかります（1フレームずつ描いてエンコードするため）
- 再生できない .mov（HEVC収録など）は、QuickTime Player で「ファイル → 書き出す → 1080p」してから追加してください
- 画面収録は画面の縦横比のまま、出力サイズに収まるように余白（黒）付きで配置されます

## 技術
- HTML / CSS / JavaScript（ビルド不要・静的サイト）
- Canvas 2D でフレーム合成、WebCodecs（VideoEncoder）+ mp4-muxer で mp4 書き出し、MediaRecorder で webm フォールバック
- IndexedDB（動画・画像）、localStorage（設定・範囲）
